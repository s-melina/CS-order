# CUTSTON Order — فرم درخواست خرید

<div dir="rtl">

فرم درخواست خرید فارسی (راست‌به‌چپ) برای **CUTSTON** به همراه صفحهٔ داخلی «کنترل و بررسی» برای واحد فروش.
پروژه کاملاً استاتیک است (HTML + CSS + JavaScript)؛ نیازی به سرور یا نصب چیزی ندارد.

## امکانات

- ثبت درخواست خرید: نام شرکت، نام شخص (اختیاری)، موبایل، شهر، محصول، سایز، تعداد، توضیحات
- اعتبارسنجی فیلدها (پشتیبانی از ارقام فارسی و عربی، نرمال‌سازی شمارهٔ موبایل ایران)
- محاسبهٔ خودکار مبلغ اولیه بر اساس محصول و سایز
- صدور شمارهٔ پیگیری برای هر درخواست (مثل `CS-261118-1234`)
- پنل بررسی فروش (`#admin`): جستجو، فیلتر وضعیت، تغییر وضعیت (جدید ← در حال پیگیری ← نهایی‌شده / لغوشده)
- خروجی اکسل (`.xlsx`) و در نبود اینترنت خروجی CSV
- پشتیبانی از حالت تیره و روشن

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا یک سرور محلی بالا بیاورید:

```bash
python3 -m http.server 8000
# بعد در مرورگر: http://localhost:8000
```

## انتشار روی GitHub Pages

1. وارد **Settings ← Pages** شوید.
2. در بخش *Build and deployment* گزینهٔ **Deploy from a branch** را بزنید.
3. شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و ذخیره کنید.
4. بعد از چند دقیقه سایت روی `https://USERNAME.github.io/REPO-NAME/` در دسترس است.

## ساختار پروژه

| فایل | کار |
| --- | --- |
| `index.html` | ساختار صفحه و فرم |
| `style.css` | استایل، حالت تیره/روشن، راست‌به‌چپ |
| `script.js` | کاتالوگ محصولات، اعتبارسنجی، ذخیره‌سازی، پنل فروش، خروجی اکسل |

## تغییر محصولات و قیمت‌ها

کاتالوگ در ابتدای `script.js` در متغیر `CAT` است. هر محصول لیستی از `[سایز به میلی‌متر, قیمت به ریال]` دارد.
قیمت‌های فعلی **آزمایشی** هستند.

## ⚠️ نکات مهم (حتماً بخوانید)

- **داده‌ها فقط در مرورگر هر کاربر ذخیره می‌شوند** (`localStorage`). یعنی درخواست ثبت‌شده توسط مشتری به دست شما نمی‌رسد و بین دستگاه‌ها هم همگام نمی‌شود. این نسخه برای نمایش و نمونهٔ اولیه است.
- **پنل `#admin` رمز ندارد** و هر کسی که آدرس را بداند می‌تواند آن را باز کند (البته فقط درخواست‌های ذخیره‌شده در مرورگر خودش را می‌بیند).
- برای استفادهٔ واقعی باید ذخیره‌سازی را به یک بک‌اند (مثلاً Supabase، Firebase یا API اختصاصی) وصل و ورود فروش را با احراز هویت محافظت کنید. تابع‌های `save`، `load` و `change` در `script.js` نقطهٔ اتصال هستند.
- اطلاعات واقعی مشتریان (موبایل، نام شرکت) را هرگز داخل مخزن commit نکنید.
- خروجی اکسل از کتابخانهٔ SheetJS روی CDN استفاده می‌کند و فونت از Google Fonts بارگذاری می‌شود؛ بدون اینترنت، خروجی CSV و فونت جایگزین استفاده می‌شود.
